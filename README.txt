PATHONEXUS — LANDING PAGE

Arquivos incluídos:
- index.html: estrutura da página
- styles.css: paleta, layout e responsividade
- script.js: menu mobile, animações e formulário por mailto
- assets/pathonexus-logo.png: logotipo otimizado e recortado
- assets/favicon-32.png, favicon-180.png e favicon-512.png

Como publicar:
1. Suba todos os arquivos desta pasta para sua hospedagem, Netlify, Vercel, GitHub Pages ou cPanel.
2. Mantenha index.html, styles.css, script.js e a pasta assets no mesmo nível.
3. No arquivo script.js, altere destinationEmail se desejar usar outro e-mail.
4. Para envio direto de formulário sem abrir o e-mail do usuário, conecte o form a Google Forms, Formspree, HubSpot ou outro CRM.
5. Atualize links de redes sociais no rodapé quando os perfis oficiais estiverem ativos.
